开源与再分发

代码与数据分开处理：代码可开放获取，数据与安装包沿用各来源的许可。

01可开放的部分

  • Android 应用源码（Kotlin，app/）与 Gradle 构建脚本。
  • 数据下载、清洗与截图脚本（Python，scripts/、tests/）。
  • 本站静态页面（docs/）。

项目尚未附带 LICENSE 文件。在选定并附上开源许可之前，依默认版权规则保留全部权利；公布许可后以该文件为准。

02不随代码发布的部分

内容状态
原始来源数据（data/raw/）不进入代码仓库，请按脚本自行取得
整理后的研究库（data/processed/）不进入代码仓库，转换不改变来源许可
含离线数据的 APK演示包，当前不作为公开再分发版本
文鼎 AR PL KaitiM GB 字体再分发须原样附带 ARPHIC-LICENSE.txt
本机配置（local.properties）不发布

03自行构建

取得源码后，按下列步骤自行下载来源数据并生成离线资料。使用数据前请先阅读来源许可，各来源条款不同，部分限于非商业或学术研究。

uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/download_sources.py
.venv/bin/python scripts/fetch_japan.py
.venv/bin/python scripts/prepare_data.py
./gradlew :app:assembleDebug

需要 JDK 17 以上、Android SDK 37 与 Python。

04再分发须知

  • 再分发代码时，保留版权与许可声明。
  • 自行构建并发布含数据的应用，须逐项满足来源的署名、非商业与禁止另站服务等条款，并保留应用内 ATTRIBUTION.txt。
  • 使用日本旧国旧郡数据（CC BY-NC 4.0）与朝鲜行政区域数据的发布，不得用于商业或对外另站服务。
  • 引用格式见来源许可。
